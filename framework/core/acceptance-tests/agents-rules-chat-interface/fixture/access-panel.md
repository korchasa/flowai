# Access panel

Product: RelayDesk.

The Scope menu offers Topic Scoped and Team Scoped. Topic Scoped grants access only to one selected project. Team Scoped grants access to every project in the team, including future projects.

The Topic field appears only for Topic Scoped and selects the project. Expires At is an absolute expiry date/time; leaving it blank means the key never expires. Grace Window is the number of hours the old key remains usable after rotation, not the validity period of the current key. It defaults to 0.

Rotate issues a new key; the previous key remains usable for Grace Window hours. Revoke disables the current key immediately. No second confirmation or automatic replacement is performed.
