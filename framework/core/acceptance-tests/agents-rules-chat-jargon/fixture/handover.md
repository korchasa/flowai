# Передача выгрузки

В заметках команды «контур» — список складов, попадающих в выгрузку. В новой версии к двум действующим складам добавлен третий.

«Опора» — сохранённая контрольная выгрузка, с которой сверяют количество отправленных записей. Она пока содержит только два склада, поэтому сравнение с новой версией не показывает, потерялись ли записи третьего.

«Хвост» — записи, не отправленные из-за обрыва соединения. Их нельзя считать отправленными и удалять до подтверждения приёма.

Мария готовит новую контрольную выгрузку для трёх складов. Илья повторно отправляет оставшиеся записи и получает подтверждение приёма. До этого новая версия выключена. Разрешение на включение: количество принятых записей совпало с контрольной выгрузкой по каждому из трёх складов, неподтверждённых записей не осталось.
