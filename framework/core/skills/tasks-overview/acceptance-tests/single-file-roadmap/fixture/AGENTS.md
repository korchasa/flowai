# Project rules — tasks

This project does not use the `documents/tasks/<YYYY>/<MM>/<slug>.md` layout described above; that section is the framework default and is superseded here. Tasks are not separate files: all of them live in `ROADMAP.md`, one `### <title>` heading per task. A task's status is the `## ` section it sits under — `In progress`, `Next` or `Done`; tasks under `Done` count as archived. The `- [ ]` / `- [x]` items under a task heading are its steps.
