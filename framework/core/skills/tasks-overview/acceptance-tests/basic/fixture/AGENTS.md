# Project rules — tasks

This project does not use the `documents/tasks/<YYYY>/<MM>/<slug>.md` layout described above; that section is the framework default and is superseded here. Tasks live in `docs/todo/<slug>.md`, one file per task, with frontmatter `state: open | blocked | closed | archived`; `closed` and `archived` tasks count as archived. Each task file has a `## Checklist` section with `- [ ]` items.
